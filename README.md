## 🧠 Who I Am

Backend engineer in training. I spent my internship at **Unicommerce eSolutions** building a production SOA alerting platform — 4 microservices, Temporal workflows, custom cache abstraction, 500+ events/day per tenant. Not a tutorial project.

I think in systems: how data flows, where bottlenecks hide, what breaks at scale. My weapon of choice is **Java 21 + Spring Boot**, and I'm equally comfortable in a Kubernetes cluster or debugging a MongoDB index that's quietly killing query latency.

```
Current obsessions:
  → Temporal workflow orchestration
  → Distributed systems design
  → Competitive programming (because suffering builds character)
  → Cloud-native infra on AWS
```
